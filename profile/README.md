# Sanestly

We build pragmatic developer tools. Open source first, privacy by default.

## Projects

**[Playwright Run Diff](https://github.com/Sanestly/playwright-run-diff)** - compare two Playwright trace runs and find behavioral regressions. Action matching, timing deltas, network and console comparison, screenshot diffs. Everything runs locally in your browser or CLI - traces never leave your machine.

```
npx @sanestly/run-diff compare baseline.zip candidate.zip
```

## What we care about

- **Local-first** - your data stays on your machine
- **Honest output** - tools that say "not enough data" instead of guessing
- **Small surface** - no accounts, no servers, no telemetry
